**# Problem 3: Count Even and Odd Numbers**

**## Problem Statement**

Count the number of even and odd elements in a given integer array.

**## Example**

Input: [4, 7, 2, 9, 6, 3]

Output:
Even: 3
Odd: 3

**## Approach**

Traverse the array and use the modulo operator to classify each element as even or odd. Maintain separate counters for both.

**## Complexity**

- Time: O(n)

- Auxiliary Space: O(1)
