**# Problem 2: Second Largest Element**

**## Problem Statement**

Find the second largest distinct element in a given integer array.

**## Example**

Input: [10, 5, 8, 10, 3, 7]

Output: 8

**## Approach**

Traverse the array while maintaining the largest and second largest distinct elements found so far.

**## Complexity**

- Time: O(n)

- Auxiliary Space: O(1)
