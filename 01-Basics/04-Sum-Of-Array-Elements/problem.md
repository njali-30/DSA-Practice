**# Problem 4: Sum of Array Elements**

**## Problem Statement**

Calculate the sum of all elements in a given integer array.

**## Example**

Input: [4, 7, 2, 9, 6, 3]

Output: 31

**## Approach**

Traverse the array and maintain a running total by adding each element.

**## Complexity**

- Time: O(n)

- Auxiliary Space: O(1)
