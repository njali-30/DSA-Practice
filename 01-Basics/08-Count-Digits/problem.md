**# Problem 8: Count Digits in a Number**

**## Problem Statement**

Count the number of digits in a given integer.

**## Example**

Input: 12345

Output: 5

**## Approach**

Repeatedly divide the number by 10 and increment the count until the number becomes 0.

**## Complexity**

\- Time: O(d), where d is the number of digits

\- Auxiliary Space: O(1)
