**# Problem 7: Palindrome Number**

**## Problem Statement**

Check whether a given integer reads the same forward and backward.

**## Example**

Input: 121

Output: Palindrome

**## Approach**

Reverse the number using digit manipulation and compare the reversed number with the original number.

**## Complexity**

- Time: O(d), where d is the number of digits

- Auxiliary Space: O(1)
