**# Problem 5: Average of Array Elements**

**## Problem Statement**

Calculate the average of all elements in a given integer array.

**## Example**

Input: [10, 20, 30, 40, 50]

Output: 30.0

**## Approach**

Traverse the array to calculate the total, then divide the total by the number of elements.

**## Complexity**

\- Time: O(n)

\- Auxiliary Space: O(1)
